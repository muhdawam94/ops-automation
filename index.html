Flagship build

AI Job Automation Platform

Python · Selenium · SQLite

A production system that ingests remote job listings from 16 sources, removes duplicates, scores relevance, drafts a tailored cover letter with an LLM, then fills and submits ATS application forms with Selenium. It runs on a schedule, logs every step, retries failures and sends proof to Telegram.

The point was never the bot — it was building a reliable pipeline with real edge cases: pagination, rate limits, flaky forms, model fallbacks and verification after submission.

  • 1,000+openings ingested
  • 16sources
  • ~90%noise filtered
  • Multipleapplications submitted
